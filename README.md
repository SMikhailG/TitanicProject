# Titanic — прогнозирование выживаемости пассажиров


Учебный проект по машинному обучению на основе соревнования
Kaggle Titanic: Machine Learning from Disaster.

Цель проекта — построить модель бинарной классификации, которая по данным
о пассажире предсказывает, выжил он после катастрофы Titanic или нет.

В проекте последовательно рассматриваются:

- исследовательский анализ данных;
- feature engineering;
- preprocessing;
- классические модели машинного обучения;
- boosting-модели;
- ансамбли;
- анализ важности признаков с помощью SHAP;
- полносвязная нейронная сеть;
- нейронная сеть с Embedding для категориальных признаков;
- кросс-валидация и сравнение результатов.

- `notebooks/TitanicKagle.ipynb` — исследовательская часть проекта:

- `main.py` — основной воспроизводимый pipeline проекта.
- `config.py` — пути, параметры cross-validation, моделей и нейронных сетей.

## Feature Engineering

В процессе исследования были созданы дополнительные признаки:

- `Family_Size` — размер семьи пассажира;
- `Family_Size_Grouped` — категория размера семьи;
- `Age_Bin` — возрастная группа;
- `Fare_Bin` — группа стоимости билета;
- `Title` — титул, извлечённый из имени пассажира;
- `Cabin_known` — известен ли номер каюты;
- `Cabin_count` — количество указанных кают;
- `Deck` — палуба пассажира.

Для числовых признаков используется заполнение пропусков медианой и
масштабирование `StandardScaler`.

Категориальные признаки кодируются с помощью `OneHotEncoder`,
а порядковый признак размера семьи — с помощью `OrdinalEncoder`.

Для DNN с Embedding категориальные признаки преобразуются в целочисленные
индексы и передаются в отдельные `Embedding`-слои PyTorch.

## Модели основного pipeline

В `main.py` сравниваются следующие модели:

- Logistic Regression;
- K-Nearest Neighbors;
- CatBoost;
- LightGBM;
- XGBoost;
- DNN;
- DNN с Embedding.

Для оценки качества используется `5-fold Stratified Cross-Validation`
с метрикой `Accuracy`.

## Результаты

Результаты текущего воспроизводимого pipeline:

| Модель | Mean Accuracy | STD |
|---|---:|---:|
| XGBoost | 0.8451 | 0.0195 |
| CatBoost | 0.8440 | 0.0055 |
| LightGBM | 0.8406 | 0.0044 |
| Logistic Regression | 0.8283 | 0.0146 |
| DNN | 0.8283 | 0.0211 |
| DNN with Embedding | 0.8260 | 0.0103 |
| KNN | 0.8227 | 0.0132 |

Лучший результат среди моделей основного pipeline показал **XGBoost**
со средней Accuracy около **0.8451**.

После кросс-валидации лучшая классическая модель автоматически обучается
на всей тренировочной выборке и используется для создания Kaggle submission.

### Результаты исследовательского ноутбука

В ноутбуке дополнительно исследовались другие классические модели,
ансамбли `VotingClassifier` и `StackingClassifier`, а также различные
варианты архитектуры и параметров DNN.

Наибольшую среднюю Accuracy в исследовательской части показал
**VotingClassifier hard — 0.8474**.

Этот результат лишь немного выше результата XGBoost — **0.8451**.
Поэтому ансамбль не переносился в основной pipeline, чтобы сохранить
итоговую структуру проекта более простой и воспроизводимой.

Результаты DNN в ноутбуке также немного отличаются от `main.py`.
В итоговом pipeline для каждого fold дополнительно фиксируется random seed,
чтобы повторные запуски нейронных сетей давали одинаковые результаты.

## Установка

Рекомендуется использовать Python 3.10.

После клонирования репозитория необходимо установить зависимости:

```bash
pip install -r requirements.txt
```

## Запуск проекта

Из корневой папки проекта выполнить:

```bash
python main.py
```

Один запуск выполняет:

1. загрузку `train.csv` и `test.csv`;
2. feature engineering;
3. preprocessing;
4. cross-validation всех моделей;
5. формирование таблицы результатов;
6. выбор лучшей классической модели;
7. обучение выбранной модели на всей тренировочной выборке;
8. предсказание для Kaggle test;
9. создание `submission.csv`.

## Выходные файлы

Результаты сравнения моделей сохраняются в:

```text
outputs/results/model_results.csv
```

Файл для отправки на Kaggle сохраняется в:

```text
outputs/submissions/submission.csv
```

`submission.csv` содержит две колонки:

```text
PassengerId
Survived
```

## Конфигурация

Основные параметры проекта вынесены в `config.py`.

Там задаются:

- `RANDOM_STATE`;
- количество folds;
- метрика оценки;
- количество интервалов для `Age` и `Fare`;
- список классических моделей;
- параметры CatBoost, LightGBM и XGBoost;
- параметры обычной DNN;
- параметры DNN с Embedding.

Это позволяет изменять основные настройки эксперимента без изменения
логики обучения моделей.

## Воспроизводимость

Для классических моделей используется фиксированный `random_state`.

Для нейронных сетей также фиксируются генераторы случайных чисел Python,
NumPy и PyTorch.

Поэтому повторный запуск:

```bash
python main.py
```

в одинаковом окружении воспроизводит результаты cross-validation
и заново создаёт итоговый `submission.csv`.
